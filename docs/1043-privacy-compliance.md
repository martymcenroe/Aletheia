# 1043 - Feature: Privacy Policy & Store Compliance

## Context
Linked to Issue #43.
Google requires a posted Privacy Policy for any extension handling user data.

## Requirements
1.  **Policy Page:** Host a static page on 'ThriveTech.ai/aletheia/privacy'.
2.  **Content:** Explicit statement that:
    * Data is stored locally (unless sync is enabled).
    * We do not sell browsing history.
    * We do not collect PII.
