## Public-Facing Notes

Initial release of Aletheia — AI-powered context analysis for selected text.

- Select any text on any webpage, right-click, and choose "Explain with AI"
- Context-aware analysis using the surrounding paragraph, not just the selected word
- Privacy-first: uses activeTab permission, only sees text you explicitly select
- Built-in content safety guardrails
- Museum Label overlay with structured analysis results
