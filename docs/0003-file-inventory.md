# 0003 - Project File Inventory

This document serves as the strict inventory of the **Aletheia** repository. It maps every file in the project to its specific architectural role.

## 📂 Root Directory
| File | Role | Description |
| :--- | :--- | :--- |
| `agent.py` | **Core Logic** | The main LangGraph agent definition and orchestration logic. |
| `checkpointer.py` | **Infrastructure** | Handles state hydration/dehydration between Lambda invocations and DynamoDB. |
| `compliance.py` | **Governance** | Logic for policy enforcement and regulatory compliance checks. |
| `deploy.sh` | **DevOps** | Automation script to build the Lambda artifact and push it to AWS. |
| `harvest_test_data.py` | **Tooling** | Local utility script that fetches captured browsing events from DynamoDB for local testing. |
| `lambda_function.py` | **Entry Point** | The AWS Lambda handler that receives API Gateway events and invokes the agent. |
| `lambda_harvester_function.py` | **Entry Point** | The AWS Lambda handler dedicated to ingesting raw events from the Chrome Extension. |
| `LICENSE` | **Legal** | The open-source license definition for the repository. |
| `poetry.lock` | **Dependency** | Exact version lockfile for Python dependencies (generated by Poetry). |
| `provision.sh` | **DevOps** | "Bare metal" AWS CLI script to provision infrastructure (DynamoDB, IAM, Lambda). |
| `pyproject.toml` | **Config** | The source of truth for project metadata and Python dependencies. |
| `README.md` | **Documentation** | The high-level project overview, quick start guide, and engineering highlights. |
| `run_guardrails.py` | **Tooling** | The local test harness for verifying the semantic guardrails engine. |
| `test_holistic_data.json` | **Data** | Local dataset of harvested words used for testing and validation. |
